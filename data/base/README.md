# Game Data
This folder is ignored by git to avoid committing copyrighted assets.

To set up the database and artwork:
1. Place your `cards.cdb` inside this `base` folder.
2. Place all `.lua` card scripts inside `script/`.
3. Place all `.jpg` or `.png` card artworks inside `pics/`.

These files are typically copied from an existing EDOPro or YGOPro installation.
